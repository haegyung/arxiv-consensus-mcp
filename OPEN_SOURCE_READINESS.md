
# Open Source Readiness

## Included

- Package source under `src/arxiv_consensus_mcp/`.
- Generic setup and runtime instructions.
- OAuth/gateway boundary documentation.
- MIT license with non-personal contributor holder text.

## Excluded

- Local `cogarch` workspace documentation, state, runs, ledgers, reports, screenshots, app bundles, virtualenvs, caches, and `.claude` worktrees.
- Machine-local absolute paths.
- Private domains, operator receipts, runtime tokens, local project names, and generated run artifacts.
- Any real `CONSENSUS_API_KEY` value.

## Current Gate

This package is a local sanitized release candidate. Public push/repository creation is intentionally not performed here.
